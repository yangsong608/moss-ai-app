## 0. 一句话定位

**手机端只回答一个问题：「现在该做什么，顺手记下来」。**

多设备、双向同步、AI 对话这些能力都在，但它们服务于这一个问题：
让用户在任何碎片时间里，打开 App 的第一屏就能看到今天的进度、今天还剩什么、并且能一行字记下新的事。

其余页面（日历 / 笔记 / 专注 / 资讯 / 会话 / 我的）是**查询与延伸**：
需要看得更全、写得更长、做得更深时才点进去，不抢第一屏。

## 1. 核心用户与场景

**用户**：有多台电脑（公司 / 家里 / 笔记本）都跑 DSH，在手机上想快速掌握今天的人。

| 场景 | 路径 | 关键要求 |
|---|---|---|
| 通勤路上看今天 | 打开 App 直接落在今天页 | 首屏不滚动就能看到日期、进度、今天还剩几项 |
| 想起一件事，马上记 | 今天页快速输入框 → 回车 | 两秒内落库，且**不打断输入**（能连按回车继续记） |
| 想知道上午干了啥 | 今天页环形进度 + 三个指标 | 完成数 / 待专注 / 高优先一眼可读 |
| 回顾某一天 | 今天页台历卡左右翻页 | 翻到哪天就看哪天的任务，今天只看未完成 |
| 改一条任务的细节 | 长按卡片 → 编辑 | 点按不弹窗（避免误触），详情走长按菜单 |
| 收掉一条做错的 | 卡片「✕ 删除」两段式确认 | 第一次点变「确认删除」，2.6 秒内再点才真删 |

## 2. 信息架构（当前实现）

```
MOSS AI App
├─ 底部 Tab（7）：今天 · 日历 · 笔记 · 专注 · 资讯 · 会话 · 我的
├─ 今天（默认落地页）──────────────────────── 本文档基准
├─ 设备与配对（index）：设备域入口、配对、切换当前域、本地域
└─ 详情层：任务详情抽屉（WorkTaskDetail）、笔记整页编辑、AI 对话页
```

**与 v1 草案的差别（已实现事实）**

| v1 草案 | 当前实现 | 说明 |
|---|---|---|
| 底部 5 Tab | **7 Tab** | 多了「笔记」独立成 Tab + 「会话」进入底部菜单 |
| 顶栏常驻设备切换器 | 顶栏显示设备徽标 + 同步态，点击进设备页 | 切换在设备页完成，避免顶栏塞下拉 |
| 「全部设备」只读聚合 | **未实现** | 一次只看一个设备域 |

**多设备数据域（已实现）**

- 一台 DSH 设备 = 一个数据域，任务 / 笔记 / 笔记本 / 专注各自独立，互不混淆。
- 当前域记在 `moss.work.device`，冷启动恢复上次选择。
- **本地域**（`LOCAL_DOMAIN_ID`）：纯手机数据，不联网；隐藏会话、资讯、AI 入口；
  可将本地数据「上传到设备」——**只增不覆盖**，复制后进同步队列。
- 今天页的快速记录可选择目标设备域（点输入框右侧设备名轮换）；目标非当前域时，
  保存前自动切域，保证任务落进那台设备的数据里。

## 3. 今天页（基准 · 按实现校准）

> 一屏回答三件事：**现在什么进度、今天还剩什么、顺手记一件**。
> 数据全部来自 `@/core/workbench`，页面只做投影和写动作，不自己存状态。
> 对照源码：`src/pages/today/today.vue`。

### 3.1 页面结构（自上而下）


### 3.2 hero 大日期卡

| 元素 | 行为 | 规则 |
|---|---|---|
| 星期 + 「今天」 | 静态 | 周一…周日，随系统时钟 |
| 月日 | `10月25日` | 随系统时钟；跨午夜自动翻篇 |
| 实时时钟 | `HH:MM:SS` 每秒刷新 | **每秒重新 `new Date()` 采样**，不用毫秒累加；后台不空转（`onHide` 停表），回前台首帧即正确 |
| 同步状态行 | `已同步 · N 台设备 · 本机可写` | N = 当前在线设备数 |
| 环形进度 | `done/total` + 百分比 | **conic-gradient** 绘制；分母是**当前设备域的全量任务**（与 `domainStats` 同口径），不是仅今天 |
| 点击环形 | 打开「清已完成」二次确认 | 已完成为 0 时只提示，不弹窗 |

> 为什么分母用全量：环形代表"这个设备域的完成度"，与设备页/我的页统计同源，
> 避免同一个数字在不同页面出现两个值。

### 3.3 三个指标

| 指标 | 取值口径 |
|---|---|
| 今日完成 | `done && date === 今天` 的任务数 |
| 待专注 | 今天覆盖到的未完成任务中，状态 **不是 waiting** 的数量（即 next + doing；这两种在卡片上 label 都是「进行中」） |
| 高优先 | 今天覆盖到的未完成任务中 `pri === high` 的数量 |

> 三个指标都只算**今天**（`tasksOnDay(tasks, 今天)`，含跨天任务落在今天的那一段），与日历同口径；
> 而环形进度的分母是**当前设备域全量**任务，两者口径不同，是刻意的：
> 指标回答"今天如何"，环形回答"这个设备域完成到哪了"。

### 3.4 快速记录（本页最高频动作）

| 行为 | 规则 |
|---|---|
| 回车即存 | `@confirm` 落库；用 `detail.value` 而非 `v-model`，避免最后一个字被吃掉 |
| **回车连建** | 保存后重新聚焦，键盘不收起；**换 `:key` 重建输入框**——只清空 `v-model` 不保证 DOM 清空（最后一击的 input 事件可能晚于 confirm 到达，实测按得越快越容易复现） |
| 新增即排期 | 开始 = **现在**，结束 = **现在 + 1 小时**，走 `scheduleTask` 写真实区间（所以日历网格里立刻可见） |
| 落在哪一天 | **永远是今天**，与台历当前翻到哪天无关。`date` 取 `todayIso`，且 `scheduleTask` 会用 `start`（现在）反推日期覆盖它。翻到别的日期时输入框仍在，记下的仍是今天的事 |
| 显示时刻 | `addTask` 先写 `when: '今天'`，随后 `scheduleTask` 把它覆盖成 `HH:MM`（如 `14:32`）。所以卡片左上角显示的是**具体时刻**，不是「今天」二字 |
| 目标设备 | 输入框右侧显示设备名，点击轮换；保存时若目标非当前域，**先切域再建任务** |
| 入口反馈 | 空输入点保存 → 提示「先写一句要记的事」 |
| 底部说明 | 左侧「回车连建 · 不打断输入」；右侧「N 项 · 待同步 M」 |

### 3.5 台历翻页卡（本页主体）

**翻页**

- 头部左右箭头（`‹` / `›`）、卡片区域左右滑动（水平位移 ≥ 44px 且大于垂直位移才触发）。
- 翻页动画 260ms，**收尾不留 transform**（避免创建 fixed 包含块，见 07 视觉规范）。
- 翻到非今天时，头部下方出现「‹ 回到今天」。
- 当前仍停在今天时，跨午夜自动跟随系统翻篇。

**卡头信息**

- 月 / 大号日 / `今天|日程 · 周六` / 农历（如「九月初五」）
- 右上：`N 项`，有已完成时追加 `· 已完成 M`

**卡片列表（每张任务卡）**

| 区域 | 内容 | 交互 |
|---|---|---|
| 顶行 | 时间 `when`、状态 chip、优先级、`⋯` | 时间逾期时高亮（匹配「截止 / 逾期」）；状态 chip 三色；优先级点按**循环** 普通→高→低；`⋯` 开长按菜单 |
| 标题 | 任务标题 | — |
| 备注 | 有则显示文本，无则显示「＋ 添加备注」 | 点按**就地**变 textarea，取消/保存两键，保存写 `note` |
| 标签 | `#标签 ✕` 逐个可删；末尾「＋ 标签」 | 点按就地出输入框，回车或失焦提交；去掉前导 `#`；重复标签静默忽略 |
| 子待办 | `已完成/总数`（如 `1/3`） | 只读展示（子待办编辑在详情抽屉） |
| 动作行 | 完成 / 删除 / 页码 | 完成：先播打勾与彩蛋 280ms 后再切状态；删除：**两段式**，第一次点变「确认删除」，2.6s 内再点才真删 |

**列表口径（重要）**

- **今天**：只列**未完成**任务，按开始时间升序（无区间的排最后）。
- **其它日期**：列**全部**任务，已完成弱化并带 ✓。
- 页脚文案随之变化：今天显示 `TODAY / 只有未完成 · 已完成在日历`，其它日期显示 `2026-10-24 / 含已完成`。
- 空态：今天「今天还没有安排」，其它日期「这一天没有任务」，并提示「左右滑动或点箭头翻页」。

**跨天区间展示**

- 起止不在同一天时，时间位显示 `10/24 22:00 → 10/25 07:00`。
- 无绝对区间的「全天」任务（`end` 只是次日 0 点的日历占位）**不显示** `00:00 → 00:00`。

### 3.6 完成彩蛋

- 勾完成时，从卡片中心爆开 **18 片纸屑**（四种主题色，随机方向/旋转，逐个 14ms 延迟），950ms 后清理。
- `lite` 模式或系统「减少动效」时**整体跳过**（连卡片动画一起），但完成动作照常执行。

### 3.7 浮层（三个，互斥）

| 浮层 | 触发 | 内容 |
|---|---|---|
| 长按操作菜单 | 卡片**长按**（点按不弹窗）或点 `⋯` | 编辑（打开详情抽屉）/ 删除；底部取消 |
| 删除确认 | 菜单删除 / 卡片删除按钮 | 说明"会从当前域移除并打 tombstone 同步"；取消 / 删除任务 |
| 清已完成确认 | 点击环形进度 | 说明将移除 N 项；取消 / 清掉 N 项 |

- 长按松手后补发的 tap 会被吞掉 700ms，避免菜单刚开又弹详情。
- 菜单/确认框打开时，底下的行不响应点击。
- 所有浮层贴合视口（`fixed; inset:0`），不随页面滚动偏移。

### 3.8 任务详情抽屉

- 入口：长按菜单 →「编辑」。
- 复用 `WorkTaskDetail`，可改标题 / 日期 / 时间段 / 子待办；「问 AI」会携带任务上下文。
- **卡片点按不开详情**（这是刻意设计：手机上手滑概率高，误弹抽屉很打断）。

### 3.9 今天页明确不做的事

| 不做 | 原因 |
|---|---|
| 清单 / 看板 / 四象限 / 时间轴 视图切换 | 收敛为单一「台历翻页卡」投影，减少选择成本 |
| 页面内搜索与筛选 | 全量任务在日历页查询；今天页只服务"今天这一刻" |
| 「已过期」聚合视图 | 逾期以卡片时间高亮表达，不另开视图 |
| 全局快速捕捉（任意页下拉） | 快速记录只放在今天页，保证落地页即入口 |
| 卡片点按开详情 | 见 3.8 |

## 5. 同步与离线（产品语义）

| 语义 | 规则 |
|---|---|
| 写入 | 本地立即生效（乐观 UI）→ 后台推送 → 失败进重试队列（显示「待同步」） |
| 冲突 | 最后写入胜出；败者保留为「冲突副本」，绝不静默丢数据 |
| 离线 | 全功能可看可记（本地库），联网后自动补推；资讯/会话需在线 |
| 删除 | 软删 + tombstone 传播（保留 30 天） |
| 跨天区间 | `date + start + end + duration` 四列无损往返，跨天任务双端一致 |
| 状态可视 | 顶栏：在线绿 / 离线灰 / 同步中蓝点 / 冲突橙 |

## 6. 视觉与动效

- MOSS / 550W × 明暗四套主题，令牌见 `src/styles/tokens.scss`。
- 卡片纹理按角色分（`hero` / `card` / `flat` / `amb`），浓度由 `tools/moss-render/check-tex.py` 按「正文对比度 ≥ 4.5:1、劣化 ≤ 35%」逐主题求解，**不能跨主题照抄**。
- 动效只用 `transform` / `opacity`；页面级入场动画只动 `opacity`，收尾写 `transform: none`（否则会创建 fixed 包含块，弹层会按页面长度定位）。
- `lite` 或 `prefers-reduced-motion` 时关闭装饰动效，保留禁用/忙碌态。
- 触控目标 ≥ 44px。

## 9. 成功指标（收敛到今天页）

- 快速记录到落库 **≤ 2s**，且连续回车建多条不丢字、不收起键盘。
- 首屏（不滚动）可见：日期 / 实时钟 / 环形进度 / 三个指标 / 快速记录入口。
