## 0. 一句话定位

**moss-ai-app 从「dsh-link 遥控器」升级为「多设备个人工作台」**：手机上管理任务/日历/专注/新闻/笔记，数据本机可用、与各台电脑上的 DSH 工作台双向同步，并能随时唤起任一设备上的 AI agent 对话干活。DSH Link 远程能力降级为其中一个功能域（连接层），不再是产品全部。

## 1. 目标用户与核心场景

**用户**：有多台电脑（公司/家里/笔记本）都跑 DSH 的个人用户，在手机上想：
- 通勤路上看今天的任务、加一条快速记录；
- 开会间隙把"想起来的事"记成任务或笔记，回到电脑上继续；
- 看各设备订阅的新闻摘要（AI 已经读过、提炼过）；
- 用番茄钟在手机上专注一段，回来把这轮挂到某个任务上；
- 对某台电脑说："把这条笔记完善一下 / 帮我把这个任务拆解"，由那台机器上的 agent 执行。

**关键场景**
| 场景 | 路径 |
|---|---|
| 通勤规划今天 | 打开 App → 今天视图（跨设备聚合或按设备查看）→ 勾选/改期 |
| 快速捕捉 | 任意页下拉/快捷按钮 → 输入一行 → 落为任务（指定设备）或笔记 |
| 移动专注 | 专注页 → 选任务 → 番茄计时 → 结束记账（挂任务） |
| 读新闻 | 新闻页瀑布流（AI 摘要为正文）→ 点原文跳浏览器 |
| 让 AI 干活 | 对话页 → 选设备 → 对该设备的 DSH 会话说话（含任务/笔记上下文） |
| 双向同步 | 手机离线改动 → 上线自动推；PC 端改动 → 手机拉取合并 |

## 2. 信息架构

```
MOSS AI App
├─ 顶栏：设备切换器（当前设备徽标 + 在线状态 + 快速切换/全部设备）
├─ 底部 Tab（5）：
│   ├─ 今天      任务（默认今天视图；清单/看板/四象限/时间轴切换）
│   ├─ 日历      周/月视图（移动端以周为主，月为辅）
│   ├─ 专注      番茄计时 + 待专注队列 + 今日专注
│   ├─ 资讯      新闻瀑布流（订阅管理入口）
│   └─ 我的      笔记 / 设置 / 设备管理 / 会话入口 / 主题
├─ 全局：AI 对话浮层（长按/侧滑唤起，绑定当前设备）
└─ 全局：快速捕捉（任意页下拉唤起）
```

**多设备模型（本产品最重要的交互决定）**
- **设备是数据的第一维度**：任务/日历/专注/新闻/笔记各有「归属设备」；会话天然属于设备（宿主实例）。
- 顶栏设备切换器常驻：`设备A` / `设备B` / **全部设备**（只读聚合视图：今天/日历/新闻可聚合；写操作仍需落到某台设备）。
- 每台设备 = 一个独立数据域（含本地存储分区 + 同步游标 + 会话列表），互不混淆；未连接的设备展示本地缓存 + "待同步"角标。
- 支持**「仅本机」伪域**：纯手机记录（不选设备的快速捕捉/临时事项落这里），永不与 PC 同步；可随时"搬"到某台设备。
- 新设备配对后走「初始化」：选择同步范围（全量 / 仅任务 / 仅笔记…）与冲突策略（默认"最后写入胜出 + 保留冲突副本"）。

## 3. 功能设计（移动优先裁剪原则）

> 裁剪原则：**手机做"看、记、轻改、专注"，重编辑留给电脑**。每个模块列出：做什么 / 不做什么。

### 3.1 任务
- **做**：今天/全部视图；清单（分组）与看板（状态列）两种投影；快速记录（一行标题，Enter 连续建）；勾完成/撤销；改状态/优先级/日期（底部抽屉）；子待办勾选；搜索/筛选（高优先级/未排时间）；通知汇总（今天完成/已过期）。
- **不做**：附件管理（只读展示已有附件名）、批量操作、字段全量编辑（descr 长文编辑回 PC）。
- **移动特色**：下拉快速捕捉；今天视图跨设备聚合开关；锁屏小组件（后续）。

### 3.2 日历
- **做**：周视图（7 天 + 今天高亮 + 任务条）、月视图（密度点）；点击任务条进详情抽屉；**长按拖拽改期**（移动手势替代桌面拖拽）；格子长按新建任务。
- **不做**：年视图（小屏价值低）、重复日程（v1 不做，见可行性文档风险）。

### 3.3 专注
- **做**：15/25/45/60 + 自定义；圆环倒计时、暂停/重置；专注队列（选任务）；**中断即记账**（按已专注分钟落 focus_sessions，completed=0）；结束弹「标记任务完成 / 再来一轮」；今日专注累计；后台运行（切 App 不中断，`endsAt` 差值方案沿用 PC 端）。
- **不做**：专注统计报表（回 PC 看统计页）。

### 3.4 新闻
- **做**：瀑布流卡片（AI 摘要为正文）、按订阅筛选、下拉刷新、点原文跳系统浏览器；订阅管理（新建/暂停/改条数）；"立即检索"按钮（触达该设备的 AI 定时链路）。
- **不做**：自定义 cron 编辑器（仅展示调度文本，改频率用预设）。

### 3.5 笔记
- **做**：笔记本切换、列表（收藏/标签筛选）、MD 编辑（轻量）与预览、自动保存（离线先落本地）、**AI 完善**（派给当前设备的 agent，回写后提示）、转为任务、分享/导出 MD。
- **不做**：PDF 导出（回 PC）、复杂富文本。

### 3.6 AI 对话（贯穿层）
- **做**：多设备会话列表（每设备独立）；流式对话、工具执行过程展示（沿用 dsh-link 现有会话转发）；genui 卡片渲染（已支持子集）；上下文携带：从任务/笔记发起时自动带引用（"关于这条笔记…"）；提问卡（choice）可回答。
- **不做**：会话归档管理、跨设备会话迁移。

## 4. 同步与离线体验（产品语义）

| 语义 | 规则 |
|---|---|
| 写入优先级 | 本地立即生效（乐观 UI）→ 后台推送到设备 → 失败进重试队列（显示"待同步"） |
| 冲突 | 同一任务双端都改：默认"最后写入时间胜出"，败者保留为「冲突副本」笔记/子待办，绝不静默丢数据 |
| 离线 | 全功能可看可记（本地库），联网后自动同步；新闻/会话需在线 |
| 删除 | 软删 + 同步；恢复入口在设置（回收站，保留 30 天） |
| 状态可视 | 顶栏设备徽标：在线绿 / 离线灰 / 同步中蓝点 / 冲突橙 |

## 5. 视觉与情感化
- 延续 MOSS 皮肤 × 明暗（tokens 复用），新增模块沿用 moss/ 原子组件；
- 桌宠「梁神」在专注页做呼吸陪伴（可关）；启动动画精简为 3s（原 12.4s 只在首次/更新后播放）；
- 无障碍：触达目标 ≥44px、动态字体、减少动效开关。

## 6. 分期规划

| 期 | 范围 | 验收 |
|---|---|---|
| **M1 本地先行** | 任务/日历/专注/笔记本地版（本机存储）+ 新闻只读（沿用现有会话能力）+ 快速捕捉 | 四模块离线全功能可用 |
| **M2 双向同步** | 协议新增工作台方法组、同步引擎（推/拉/冲突）、多设备数据域、设备聚合视图 | 双端改动 30s 内互见；断网重连不丢不重 |
| **M3 AI 深化** | AI 对话上下文携带（任务/笔记）、笔记 AI 完善回写、新闻订阅管理+立即检索、专注-任务联动 | "手机说、电脑干、手机看结果"闭环 |

## 7. 成功指标
- 快速捕捉到落库 ≤2s；同步冲突率 <1%（日）；笔记 AI 完善回写成功率 >95%；
- 移动端日活中"今天视图"打开率 >60%；专注完成率（跑满+中断记账）>80%。
