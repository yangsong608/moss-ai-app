# 打包与发布（P2-4）

> 适用：moss-ai-app（uni-app 3 / Vue3）。覆盖 H5、Android、iOS 三条产物线，以及发布前检查清单。

---

## 1. 发布前检查（每次必跑）

```bash
npm run check      # typecheck + 协议测试 + 映射测试 + build:h5 + smoke(6 路由)
node scripts/e2e-sync.mjs --write   # 需 DSH 已加载带 /sync 的工作台插件
```

- [ ] `check` 全绿（当前约 40s）
- [ ] `e2e-sync --write` 通过（push 探针 → delta 拉到 → 删除）
- [ ] 版本号已改：`package.json` `version`、`src/manifest.json` `versionName` / `versionCode`
- [ ] `protocol/` 与 `dsh-link-suite/shared/protocol` 一致（`diff -rq`）

## 2. H5

两条构建线，产物目录不同，验收脚本都支持：

```bash
# A. uni CLI（CI/日常）
npm run build:h5                     # 产物 dist/build/h5
node scripts/smoke.mjs               # 默认验 dist/build/h5

# B. HBuilderX（对外发行，官方编译器）
/Applications/HBuilderX.app/Contents/MacOS/cli open
/Applications/HBuilderX.app/Contents/MacOS/cli publish web \
  --project "$PWD" --webTitle "MOSS AI App"
# 输出：dist/build/web
node scripts/smoke.mjs --dir dist/build/web
```

> 实测（2026-10-24）：HBuilderX v5.26 `publish web` 编译成功，产物 768KB，
> 六条路由 smoke 全过、浅色卡片观感与 uni CLI 产物一致。
> 注意：HBuilderX 构建会**重建** `dist/build`（保留 `web`，清掉 `h5`），
> 之后跑 `npm run check` 会重新生成 `dist/build/h5`，两者互不干扰。

- 部署方式：任意静态托管（Nginx/对象存储/uniCloud）。**必须支持 hash 路由**（本项目用 `#/pages/...`），无需服务端 rewrite。
- 校验：`node scripts/smoke.mjs`（脚本会自己起本地静态服务，不依赖部署环境）。
- 注意：H5 的存储走 uni storage（localStorage 封装），配额小于原生 SQLite；数据量大时提示用户用 App。

## 3. Android（HBuilderX）

1. HBuilderX 打开 `moss-ai-app/`（项目根，含 `src/manifest.json`）。
2. 发行 → 原生 App 云打包：选择 Android，使用自有证书或公共测试证书。
3. 权限已声明（`app-plus.distribute.android.permissions`）：
   - `INTERNET`、`ACCESS_NETWORK_STATE`、`CAMERA`（扫码配对）
4. 产物：`.apk` / `.aab`。安装后首次连接需与电脑同一局域网。

### 局域网连通性排查（Android）
- 手机与电脑同一 Wi-Fi（或电脑热点），且**路由器未开启 AP 隔离**。
- DSH 侧 `dsh-link` 网关默认 7443；确认没被防火墙拦截。
- 连接失败先看 App 内设备页错误码：`needs-auth`（令牌失效，需重新配对）/ 超时（网络不通）。

## 4. iOS（HBuilderX）

1. 发行 → 原生 App 云打包：iOS，需 Apple 开发者证书与描述文件（或使用 TestFlight 分发）。
2. **权限已声明**（`app-plus.distribute.ios.privacyDescription`）：
   - `NSLocalNetworkUsageDescription`：局域网访问说明（缺这个会**静默失败**、只有无错误超时）
   - `NSBonjourServices`：`_dshlink._tcp`（若后续接入 Bonjour 自动发现）
3. 首次连接局域网时系统会弹「允许访问本地网络」，必须点允许。

## 5. 版本与兼容

| 项 | 约定 |
|---|---|
| App 版本 | `package.json` version 与 `manifest.versionName` 保持一致 |
| 协议版本 | `protocol/` 的 `PROTOCOL_VERSION`；不和 App 版本混用 |
| 能力协商 | 老网关无 `wb.*` 时 `caps.workbench=0`，App 自动降级为「本地 + 遥控器」，不崩 |
| 数据兼容 | 存储键带域（`moss.work.<deviceId>`）；升级不清库 |

## 6. 已知限制（发布说明里要写）

- 手机端任务/笔记的**附件**只同步元信息（宿主侧附件内容在 M2 之外）。
- 冲突采用「最后写入胜出 + 冲突副本」，不提供字段级合并 UI。
- 同步需要 DSH 侧工作台插件 ≥ 含 `/sync/*` 的版本（本次 P1-1 之后）。
- H5 端在部分浏览器下存储配额较小，建议 App 端使用。
