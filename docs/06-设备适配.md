# 设备适配（手机 / 平板 / 联想 Y700）

> 日期：2026-10-24 ｜ 关联：`src/components/WorkShell.vue`、各页面媒体查询、`docs/05-打包与发布.md`

## 1. 联想 Y700 的真实尺寸换算

| 项 | 值 |
|---|---|
| 屏幕 | 8.8 英寸，2560 × 1600（16:10） |
| 典型 DPR | 2（部分系统设置 2.5/3，WebView 按实际 DPR 换算） |
| **横屏 CSS 尺寸** | **1280 × 800**（2560/2 × 1600/2） |
| **竖屏 CSS 尺寸** | **800 × 1280** |
| 安全区 | 横屏左右各约 0–16px（手势/边框），竖屏底部约 20px |

> 结论：横屏 1280 宽**不是手机**，必须有平板布局；竖屏 800 宽也应走平板布局（不是手机底部 Tab）。

## 2. 断点定义（唯一来源）

| 条件 | 布局 | 谁在用 |
|---|---|---|
| 宽 < 760，或 高 < 520 | **手机**：底部 Tab、单列、详情底部抽屉 | 手机竖屏、手机横屏（844×390） |
| 宽 ≥ 760 且 高 ≥ 520 | **平板**：左侧竖栏导航（84px）+ 内容自适应 | Y700 横屏 1280×800 / 竖屏 800×1280、iPad |
| 宽 ≥ 1100 | **宽屏**：内容区 max-width 1180，双列/三列（清单两列、专注左右两栏、资讯三列） | Y700 横屏 1280 |

**为什么不用单一 900 阈值**：手机横屏（844×390）宽度也接近 800，只按宽度会把手机误判成平板；加 `min-height: 520` 就能区分。

## 3. 各页面内的局部断点

| 页面 | 规则 |
|---|---|
| 今天 | ≥1000：内容限宽 860 居中；≥1100：任务卡两列 |
| 日历 | 周视图横向滚动，时间轴 sticky；月视图 7 列 |
| 笔记 | ≥820：左列表右编辑（笔记编辑器为整页页面 `note-edit`） |
| 专注 | ≥1100：左计时 + 右队列 |
| 资讯 | ≥700 两列、≥1100 三列 |

## 4. 自测方法

```bash
npm run build:h5
# 起服务后按三档截图/断言（脚本已内置 390/820/1280 三档）
node scripts/smoke.mjs
```

手工核对清单：
- [ ] Y700 横屏（1280×800）：左侧竖栏出现、底部 Tab 消失、清单两列
- [ ] Y700 竖屏（800×1280）：左侧竖栏出现（不是底部 Tab）
- [ ] 手机竖屏（390×844）：底部 7 Tab、单列
- [ ] 手机横屏（844×390）：仍为手机布局（高 < 520）
