# MOSS AI App · 视觉与动效规范（炫酷版 v1）

> 目标：设备与配对页做成"炫酷控制台"，其它页面统一操作反馈。所有实现必须 uni-app 跨端可用（只用 transform/opacity/渐变，不用 blur/backdrop-filter，不用 canvas）。

## 1. 视觉基元

| 基元 | 做法 | 参数 |
|---|---|---|
| 极光底 | 两层 radial-gradient 缓慢漂移（只动 transform） | 24s ease-in-out 循环，位移 ≤6% |
| 流光边框 | 卡片外圈 1px 渐变光带旋转（conic-gradient + mask） | 6s linear，仅"当前/在线"设备用 |
| 玻璃卡 | 半透明底 + 1px 半透明描边 + 大圆角 + 柔阴影 | radius 18–22px，阴影 y=10 blur=28 alpha≤.12 |
| 雷达呼吸 | 状态点外圈扩散环 | 1.8s ease-out，scale 1→1.9 + opacity .5→0 |
| 数字等宽 | 计数/时间/延迟用 mono 字体 | 与现有 `--mono` 一致 |

## 2. 动效规范

| 场景 | 动画 | 时长/曲线 |
|---|---|---|
| 页面/卡片入场 | 上浮 8px + 淡入，按 30–60ms stagger | 260ms cubic-bezier(.22,1,.36,1) |
| 列表项入场 | 每条 30ms 递进，最多前 8 条（长列表不卡） | 220ms ease-out |
| 按钮按下 | scale(.97) + 亮度 -4% | 90ms ease-out |
| 卡片 hover/按下 | translateY(-1px)/scale(.99) | 120ms ease-out |
| 勾选完成 | 圆点 pop + 对勾描线 | 280ms spring |
| 状态切换（皮肤/Tab/选中） | 颜色/背景 160ms 过渡 | ease-out |
| 提示 toast | 上浮 6px 淡入 + 自动消失 | 200ms / 2s |
| 骨架/空态 | 呼吸 opacity .55↔1 | 1.6s |
| 减少动效 | `prefers-reduced-motion` 或 `state.lite` 时全部关闭 | 硬规则 |

## 3. 设备与配对页（控制台）

- 顶部「MOSS 状态台」：品牌 + 在线计数大数字 + 雷达扫描线（一条横向光带 4s 往返）+ 连接状态 pill。
- 设备卡：白卡/玻璃卡 + 在线流光边框 + 状态点呼吸 + 数据量四格 + 底部主操作。
- 本地域卡：与设备卡同族但**虚线描边 + 独立图标**，一眼区分"不联网"。
- 配对 dock：主按钮实底渐变 + 按下回弹；副入口文字链。
- 待确认配对：琥珀色脉冲边框（2s），引导用户处理。

## 4. 其它页面统一反馈

- Tab 切换：内容区 120ms 淡入（不整页闪烁）。
- 任务勾选：打勾动画 + 行淡出 120ms。
- 新增任务/笔记：新卡片入场 stagger；删除：卡片 120ms 收缩淡出。
- 所有主按钮：按下 scale + 松手回弹；加载态按钮禁用并显示进度点。
- 空态：图标呼吸 + 一句可执行建议（不是干巴巴"暂无数据"）。

## 5. 性能与兼容

- 只动 `transform` 与 `opacity`；渐变背景本身不动（只动 transform）。
- 不用 `backdrop-filter`、`filter: blur()`、canvas、内联 SVG 动画。
- 长列表只对前 8 条做 stagger；`state.lite` 或系统减少动效时全部动画退化为无动画。
