## 三、依赖与风险

- **P0-1 与 P0-2 互相影响**：外壳统一后才能确定设备域的入口位置 → 先做 P0-2 的数据映射，再收外壳。
- **P1-1 是 P1 的关键路径**：工作台改造不完成，手机端同步无正确语义（快照 LWW 会互踩）。
- **协议双份**：`dsh-link-suite/shared/protocol` 与 `moss-ai-app/protocol` 必须同改（README 有约定）。
- **验收工具**：H5 用 hash 路由 + headless 截图/文本抽取（本机已有可用脚本模式）。

## 四、立即可以开工的下一步

建议顺序：**P0-2 设备域映射 → P0-1 导航统一 → P0-3/4 交互补齐 → P1-1 工作台改造**。
理由：前三项都在 App 侧，改动小、每天可见；P1-1 一旦开始就是跨仓库大改，适合在前端稳定后集中做。
